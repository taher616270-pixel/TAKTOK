# TAKTOK

واجهة أولية متقدمة لمنصة فيديوهات قصيرة، مبنية كتجربة استخدام مستقلة باسم TAKTOK.

## التشغيل
افتح `index.html` عبر استضافة صفحات ثابتة أو خادم محلي.

## ما هو موجود
- تجربة صفحة فيديو عمودية مع تمرير تلقائي وعناصر تفاعل.
- صفحات الأصدقاء والاكتشاف والبحث والنشر والملف الشخصي والوارد والإعدادات.
- اختيار صورة أو فيديو ومعاينته قبل النشر.
- تفاعلات وبيانات ملف شخصي محلية على الجهاز.

## حدود النسخة الحالية
هذه نسخة **Frontend prototype** وليست تطبيقًا متصلًا بخادم:
- لا يوجد تسجيل دخول أو إنشاء حساب فعلي.
- الرسائل والإشعارات والبث المباشر غير متصلة بخدمات حقيقية.
- المنشورات المحلية لا تُرفع إلى الإنترنت، وملفات الوسائط المختارة متاحة للمعاينة خلال الجلسة فقط.
- أرقام المتابعين وبعض محتوى العرض تجريبي.

## المرحلة التالية
بعد اعتماد الواجهة وتجربتها، يمكن تصميم وربط API وقاعدة بيانات وتخزين وسائط ونظام حسابات ومحادثات وإشعارات.
